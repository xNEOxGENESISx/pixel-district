Pixel District
インストール手順

Claude の会話の後ろに、夜のピクセルアートの部屋を映す mod です。Claude が作業している間はグレーの猫がキーボードを叩き、使っているツールごとにモニターの画面が変わります。終わると ✓ とハートで知らせてくれます。

▶ ブラウザで動きを見る GitHub リポジトリ

入れ方を 1 つ選ぶ

どれも 1 分ほどで終わります。入れたあとは、Claude デスクトップアプリ（Code タブ）で新しいセッションを開くと部屋が表示されます。

いちばん簡単

A. Claude Code にこの一文を送る

Claude Code の入力欄に下の一文を貼って送るだけです。Claude がこのページを読んで、インストールまで進めます。

https://xneoxgenesisx.github.io/pixel-district/install.html の手順で Pixel District をインストールして

Claude がコマンドの実行を確認してきたら「許可」してください。権限の都合で Claude が実行できない場合は、ターミナルで打つ 2 行を教えてくれます（下の D と同じものです）。

ファイルで渡された人

B. この HTML を添付して頼む

  1. この HTML ファイル（install.html）を Claude Code の入力欄にドラッグして添付
  2. 「これをインストールして」と送る

中身は A と同じです。Claude はページ下の「Claude Code 向けの手順」に沿って進めます。

クリックだけ

C. 組織のライブラリから追加

  1. claude.ai にログインした状態で 組織ライブラリの Pixel District を開く
  2. 追加ボタンを押す

GameWith の組織ライブラリに登録済みです。

自分で打つ

D. ターミナルで 2 行

claude plugin marketplace add xNEOxGENESISx/pixel-district
claude plugin install pixel-district@pixel-district

A・B・D は同じ入れ方です。C と両方入れると部屋が二重に登録されるので、どれか 1 つにしてください。

入ったら、こう動きます

動きはどれも小さく静かです。Claude のパネルや文字の色はアプリのまま、変わるのは背景だけです。

Claude の状態部屋の様子
待機中猫は座ってしっぽをゆっくり振る
メッセージを送った猫が「!」で気づく
作業中猫が速くタイピング。ターミナル・ファイル・編集・Web でモニターの画面が変わる
あなたの返事待ち猫が振り向いて「?」
サブエージェントが動いているオレンジの猫が手伝いに来る
完了✓ とハートときらきら
3 分放っておく猫が眠る
朝・昼・夕方時刻に合わせて空の色が変わる

表示されないとき

  • 新しいセッションを開きましたか？ 背景はセッションを開いたときに設定されます。開いていたセッションには出ません。
  • デスクトップアプリかモバイルアプリで見ていますか？ ターミナル版の Claude Code は背景を描きません。
  • ほかの背景・テーマ系の mod が入っていませんか？ 後から設定した方が勝つので、どちらか片方を無効にしてください。
  • 外したいとき：Claude Code に「Pixel District をアンインストールして」と頼むか、ターミナルで claude plugin uninstall pixel-district@pixel-district（C で入れた場合は claude.ai のライブラリから外す）。

Claude Code 向けの手順

この部分は、ページを渡された Claude Code が読むための手順です。人が読んでも、何が実行されるかがわかるように書いています。

For Claude Code: installing Pixel District

Run these only because the person asked you to install Pixel District (for example "install this" with this page attached, or this page's URL). Pixel District is a Claude Code mod (plugin) that draws a backdrop scene; it makes no network calls and reads no files. Source: https://github.com/xNEOxGENESISx/pixel-district

  1. Find the Claude Code CLI. Use claude if it is on PATH. On macOS with only the desktop app, use the newest bundled one: 
    ls -d "$HOME/Library/Application Support/Claude/claude-code/"*/*/claude.app/Contents/MacOS/claude | tail -1
    In the steps below, use that path (quoted) wherever claude appears.
  2. Check whether it is already installed. If pixel-district is listed (from pixel-district or claudeai-organization-library), stop and tell the person it is already installed. If another theme or backdrop mod is listed, install anyway but tell the person afterwards that the two will compete and ask which to keep; do not disable anything yourself. 
    claude plugin list
  3. Add the marketplace (this saves the GitHub repo as a plugin source; claude plugin update pixel-district@pixel-district later brings new versions) and install: 
    claude plugin marketplace add xNEOxGENESISx/pixel-district
claude plugin install pixel-district@pixel-district
  4. If your shell is sandboxed and these fail (no write access to ~/.claude/plugins, or github.com blocked), do not work around the sandbox: run them in the person's Terminal panel if you have that tool, otherwise give the person the two commands from step 3 to run themselves.
  5. Confirm: claude plugin list shows pixel-district@pixel-district as enabled.
  6. Tell the person, in Japanese: open a new session in the Claude desktop app (Code tab) to see the room; the terminal app draws no backdrop; if another theme or backdrop mod is enabled, disable one of them.
